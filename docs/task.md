# News API

**[News API](https://newsapi.org/)** — это простой HTTP REST API для поиска и получения новостей из Интернета.

## Ключевые навыки

- Классы JavaScript
- Модули в JavaScript
- Webpack
- TypeScript

## Источник

[Оригинальное приложение](https://github.com/rolling-scopes-school/news-JS/)

### Прокси

- News API больше не позволяет вызывать API из других источников, кроме localhost.
- Прокси-сервер News API для использования в развернутой версии:
    - <https://rss-news-api.onrender.com/> — имеет дополнительные mock-эндпоинты — `/mocks/sources` и `/mocks/everything` — которые возвращают статические данные, чтобы помочь предотвратить исчерпание лимита запросов к API-ключу в процессе разработки.

## Требования к заданию

- Создайте собственную копию приложения.
- Добавьте [TypeScript](https://www.typescriptlang.org/) в проект.
- Настройте [ESLint](https://eslint.org/) для работы с TypeScript.
- Настройте [Webpack](https://webpack.js.org/) для работы с TypeScript.
- Переведите приложение с JavaScript на TypeScript, используя:
    - Перечисления (Enums)
    - Интерфейсы (Interfaces)
    - Типы (Types)
    - Обобщения (Generics)
    - Объединённые типы (Union Types)
    - Модификаторы доступа (`private`, `public`)
    - Утилитарные типы (`Partial`, `Pick`, `Readonly`)
- Сделайте вёрстку адаптивной с дизайном на ваше усмотрение.

**Использование типа `any` СТРОГО ЗАПРЕЩЕНО!**

## Последовательность выполнения задания

### Шаг 1: Начальная настройка приложения

На этом шаге мы достигли следующего:

- Интегрировали TypeScript в проект, добавив npm-пакет TypeScript.
- Создали файл `tsconfig.json`.
- Настроили ESLint и Webpack для бесшовной совместной работы с TypeScript.
- Внедрили плагин [typescript-eslint/recommended](https://www.npmjs.com/package/@typescript-eslint/eslint-plugin) в ESLint.
- Успешно запустили вашу версию приложения.

### Шаг 2: Подготовка к миграции кода на TypeScript

Результат выполнения этого шага включает:

- Переименование файлов с расширением `*.js` в файлы с расширением `*.ts`.
- Создание необходимых интерфейсов для обмена данными с [News API](https://newsapi.org/).

### Шаг 3: Миграция кода на TypeScript

Результат выполнения этого шага следующий:

- Код строго типизирован, включая:
    - Объявление типов для всех переменных.
    - Типизацию параметров функций и методов, а также корректную обработку случаев, когда функции не возвращают значение.
    - Типизацию используемых классов.
    - Ранее созданные интерфейсы используются в коде.
    - Созданы и используются перечисления, обобщения, утилитарные типы и т.д.
- Файл конфигурации TypeScript включает следующие флаги:
    - `"noImplicitAny": true`
    - `"strict": true`
- В ESLint включено правило `no-explicit-any`.

### Шаг 4: Адаптивная вёрстка

Результат выполнения этого шага:

- Вёрстка сохраняет стабильность при масштабировании, обеспечивая адаптивность элементов без перекрытия или выхода за пределы области просмотра.
